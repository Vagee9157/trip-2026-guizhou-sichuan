## 行程

贵阳 → 黄果树 → 乐山 → 成都 → 都江堰 → 青城山

- 9.27 贵阳会合
- 9.28 黄果树（门票＋水帘洞已约）
- 9.29 乐山坐船，晚上落成都
- 9.30 都江堰，6 号门进
- 10.1 武侯祠 → 锦里 → 文殊院
- 10.2 青城山前山
- 10.3 放空日，杜甫草堂
- 10.4 双流 T2 返程
